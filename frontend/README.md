# 原 React 后台构建产物

此目录是嵌入 Go 的上游 React 构建资源，不包含对应 React 源码。Nuxt 前台源码位于 `web/`。

本分支移除了系统概览中的打赏卡片、名单加载逻辑及对应多语言翻译。帮助反馈链接指向当前分支 Issues，移除社群入口，原二进制升级操作改为打开 Docker 升级文档。系统设置中的其他功能保留；概览不再为打赏卡片保留空列。

修改后的设置与语言模块使用新文件名。HTML 在入口模块前通过 import map 映射旧模块路径，避免浏览器一年期静态缓存继续执行旧打赏模块；旧文件仅重导出新模块，兼容现有 preload 引用。原文件、gzip 和 Brotli 版本同步维护。

以后替换上游后台构建资源时，应优先从对应 React 源码重新构建，并检查打赏模块是否重新引入。届时若构建生成了完整的新资源引用，应删除这里的兼容映射和旧模块重导出文件。
